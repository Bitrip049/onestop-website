# One Stop Gutter & Solar Cleaning — logo files

## svg/ (vector, any size, for print and web)
- onestop-horizontal-*.svg  — main logo, mark beside the name
- onestop-stacked-*.svg     — square-ish lockup for signage, social, van door
- onestop-mark-*.svg        — mark only: favicon, app icon, avatar, stamp

Colour versions
- color   — red mark, ink text, for white / light backgrounds (default)
- reverse — white mark and text, for the red background only
- dark    — red mark, white text, for the dark ink background
- mono    — one-colour ink, for invoices, stamps, fax-grade print

## png/ (ready-to-use bitmaps, 4× resolution)
- horizontal and stacked on transparent, mark on transparent
- on-red and on-ink versions include their background

## Rules
- Clear space around the logo: at least the height of the mark's gutter bar on every side.
- Minimum size: mark 16px / 5mm; horizontal logo 120px / 35mm wide.
- Do not round corners, rotate, add shadows or recolour. Red is #EC3013, ink is #201E1D, white is #F3F2F2.
- Font is Archivo (free, Google Fonts). The SVG files reference it online; for a print shop send the PNGs or ask for an outlined version.
